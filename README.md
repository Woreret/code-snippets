# Code Snippets

## Опис функціоналу та особливостей
*   **Стилізація Glassmorphism:** Для карток використано напівпрозорі фони з ефектом розмиття `backdrop-filter: blur` на темному фоні.
*   **Збереження у localStorage:** Додаток працює без бекенду та бази даних. Усі сніпети записуються в локальне сховище браузера, тому дані не зникають після оновлення сторінки чи закриття вкладки.
*   **Копіювання коду:** Реалізовано копіювання тексту в буфер обміну за допомогою Clipboard API. При кліку на кнопку "Copy" її текст змінюється на "Copied!".
*   **Структура на класах:** Логіка JavaScript побудована на основі об'єктно-орієнтованого підходу з використанням класів (`Snippet`, `snippetManager`, `sendCode`).

## Як це працює
1.  Потрібно відкрити `index.html` у браузері.
2.  Заповнити текстові поля: назву сніпету, мову програмування та сам код.
3.  Натиснути кнопку "Save Snippet".
4.  Сніпет додається у список нижче, де його можна скопіювати або видалити.

## Технологічний стек
*   HTML5
*   CSS3 (Flexbox, CSS-змінні, анімації)
*   JavaScript (ES6+, класи)
